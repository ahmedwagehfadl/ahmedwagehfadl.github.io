AF Gaming Live Tools is the private, single-channel publishing tool of the independent game studio AF Gaming (games: Ra Wormates, Rise of Ka). It runs only on the studio owner's own computer and is used only for the studio's own YouTube channel @afgaming_studio. It is not offered to other users.

What it does with YouTube API Services

  • Before and during each live stream of our own gameplay, it sets the broadcast's title, description and category (liveBroadcasts.list, liveBroadcasts.update, videos.update).
  • It uploads short clips (YouTube Shorts) cut from our own live streams to our own channel (videos.insert).
  • It reads our own channel's basic information to confirm the connection (channels.list).

It does not access any other user's data, does not read comments, subscribers or analytics, and does not display YouTube content to third parties.
