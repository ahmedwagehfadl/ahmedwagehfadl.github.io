AF Gaming Live Tools - Privacy Policy

Last updated: 21 November 2026

Who we are

AF Gaming Live Tools ("the tool") is a private publishing tool operated by Ahmed Fadl (AF Gaming, Eisenstadt, Austria) for the AF Gaming YouTube channel only. Contact: ahmedwageehfadl@gmail.com.

Use of YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

With the channel owner's permission (OAuth scopes youtube and youtube.upload) the tool accesses only the owner's own channel: the channel's ID and title, the owner's own live broadcasts (ID, title, description, status) and the videos the tool uploads. It does not access any other person's data, comments, subscribers, analytics or contacts.

How the data is used

Only to set titles, descriptions and the category of the owner's own live broadcasts and to upload the owner's own short clips. No data is used for advertising, profiling or any other purpose.

Storage and sharing

The tool stores only an OAuth refresh token, as a Windows user environment variable on the owner's own computer. API responses are used in memory and not stored, except a local text log of the titles that were published. No data is sold or shared with third parties. The tool does not use cookies and has no other users. The text of titles and descriptions may be drafted with Google's Gemini API from gameplay statistics; no YouTube user data is sent to it.

Retention and deletion

The owner can revoke the tool's access at any time at Google security settings (third-party access); deleting the environment variable removes the stored token. Local logs can be deleted at any time. Questions or deletion requests: ahmedwageehfadl@gmail.com.

Changes

Changes to this policy are published on this page with a new date.
